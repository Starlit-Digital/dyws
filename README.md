# Cravings & Delight

Private source archive for the restaurant website.

The deployable static website is in `public_html/`. Serve this directory with any static web server. The preview lives at https://sltd.ca/preview/cravings-4fe5c6f3d9a59082/ .

The design uses charcoal, bronze and white, with a menu first layout, responsive food photographs, a 32 step appearance slider and font sizes from 21 to 28 pixels. Restaurant content and photographs originate from cravingsanddelight.ca.

See `docs/preview-history.md` for source and deployment history. The preview URL is unlisted, not authenticated. Delivery partner links are demonstrations.
