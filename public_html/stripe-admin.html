Stripe payments

Use a restricted API key from a Stripe sandbox with Checkout Sessions read and write permissions and the permissions needed to create its Prices, Products and PaymentIntents. This demo accepts test keys only.

Keys are sent to your server over HTTPS, encrypted in private server storage and never returned to the browser.

Required webhook destination:

Listen for checkout.session.completed, checkout.session.async_payment_succeeded, checkout.session.async_payment_failed, checkout.session.expired and charge.refunded. A returned checkout page alone never marks an order paid.
