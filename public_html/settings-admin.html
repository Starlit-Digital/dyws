Google Maps

Show the driver, delivery destination and driving route on the admin, driver and private order pages.

For this prototype, get a free Google Maps Demo Key with a personal Google account. No billing details are required. Daily limits apply.

For a standard key, enable Maps JavaScript API and Routes API, then restrict the key to your website, https://sltd.ca/*, and those two APIs only. Browser keys are visible to visitors by design.

Map connection

DEMO_MAP_ID is suitable for testing. Each page reuses one map as GPS updates arrive. Map tiles are cached only by Google's SDK. GPS stays in memory, with its original timestamp. A last known fix can remain during an active session for up to 15 minutes, and clears within two minutes if updates stop.
