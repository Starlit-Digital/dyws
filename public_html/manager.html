About these reports

Dates use the timezone selected in Settings. Payment totals use payment dates; order totals use creation dates. The dashboard excludes cancelled orders from ordered value and average order. Popular items use stored item snapshots and do not represent paid sales. Payment totals include tax and delivery fees. Previous periods use the same number of calendar days. Completion rates use current order status, not a historical snapshot. The board shows the latest 200 orders.
