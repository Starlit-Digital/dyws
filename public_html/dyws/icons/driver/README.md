# Driver icon artwork

Six fixed local SVG markers. Car is the default. The surrounding navy, gold and cream marker uses the DYWS palette and a pointed location anchor.

Car, van, motorcycle and bicycle use [Lucide](https://github.com/lucide-icons/lucide) outlines under the included ISC license. SUV uses Tabler car-suv, and pickup adapts Tabler truck to an open cargo bed, under the included [Tabler](https://github.com/tabler/tabler-icons) MIT license. Sources were retrieved October 24, 2026. These functional vehicle symbols are not product logos.

The icon describes a profile preference. It does not change Google routing mode, confirm a vehicle type or imply live heading. No user SVG, URL or uploaded image is accepted.
